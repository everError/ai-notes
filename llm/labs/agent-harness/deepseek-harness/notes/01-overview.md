## 설계 원칙: 모든 것이 플러그인

Cordis 기반으로 구성 요소 전부를 플러그인으로 취급한다. 모델, 도구, 스킬, 세션,
샌드박스, 파일 시스템, 에이전트 루프, 사용자 인터페이스가 모두 교체 및 확장 대상이다.
특정 모델이나 특정 인터페이스에 고정되지 않는 것이 이 구조의 목적이다.

일반적인 하네스가 모델 계층만 교체 가능하게 두는 것과 달리, 에이전트 루프 자체를
교체 지점으로 열어둔 점이 특징이다.

플러그인은 npm 패키지로 배포되며 프로필 단위로 설치된다. 실제 설치 구조는
`02-dsh-home-layout.md` 를 참고한다.

## 모델 프로바이더

- 기본 내장: DeepSeek
- 카탈로그: Anthropic, OpenAI, Bedrock, Vertex, Azure, Codex
- 커스텀: OpenAI 호환 게이트웨이 또는 자체 호스팅 서버를 직접 등록

커스텀 프로바이더를 지원하므로 Ollama, vLLM 같은 로컬 서버를 붙일 수 있다.
설정은 `$DSH_HOME/settings.yaml` 의 `llm-pi-ai.providers` 아래에 기록된다.
프로바이더 지원은 하네스 본체가 아니라 `@anthropic-ai`, `@google`, `@mistralai`,
`@aws-sdk` 같은 개별 패키지로 분리되어 있다.

## 자격 증명 처리

시작 시 다음 순서로 자격 증명을 읽는다.

1. 프로세스 환경 변수
2. `$DSH_HOME/.credentials.yaml` (관리 저장소, 기본 경로는 `~/.dsh`)
3. 작업 디렉터리의 `.env`
4. `$DSH_HOME/.env`

웹 인터페이스에서 저장한 키는 `.credentials.yaml` 에 기록되고, 설정 파일에는 참조만
남는다. 저장 후 화면에는 가려진 값만 표시된다. macOS와 Linux에서는 자격 증명 파일
권한이 0600이 아니면 실행을 거부한다.

## 확인한 사항

- MCP 서버 연결을 지원한다. `@modelcontextprotocol` 패키지가 기본 프로필에 설치된다.
- 프로바이더와 기능이 npm 패키지 단위로 분리되어 있다.

## 확인이 필요한 사항

- 컨텍스트 압축 방식과 장시간 작업에서의 안정성
- 플러그인 작성 난이도와 공개된 확장 지점의 범위
- MCP 서버를 등록하는 구체적인 절차
- 로컬 소형 모델에서의 에이전트 루프 완주율
